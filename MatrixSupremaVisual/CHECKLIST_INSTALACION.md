# ✅ Checklist de Instalación y Verificación

## 📋 Lista de Verificación Completa

Usa este checklist para asegurar que todo funciona correctamente.

---

## 1️⃣ ANTES DE INSTALAR

### Requisitos
- [ ] Tengo Power BI Desktop instalado (versión reciente)
- [ ] He descargado el archivo `MatrixSupremaVisual.pbiviz`
- [ ] Sé dónde está guardado el archivo .pbiviz
- [ ] Tengo datos en la tabla `negativosBi`

---

## 2️⃣ INSTALACIÓN

### Importar Visual
- [ ] Abrí Power BI Desktop
- [ ] Fui al panel de Visualizaciones
- [ ] Hice clic en los tres puntos `...`
- [ ] Seleccioné "Importar un visual desde un archivo"
- [ ] Elegí `MatrixSupremaVisual.pbiviz`
- [ ] Acepté el aviso de seguridad
- [ ] Veo el nuevo icono en el panel de visualizaciones

---

## 3️⃣ CONFIGURACIÓN BÁSICA

### Agregar Visual al Reporte
- [ ] Hice clic en el icono de Matrix Suprema
- [ ] La visual aparece en mi página
- [ ] Redimensioné la visual a un tamaño cómodo (mínimo 600x400px)

### Configurar Campos
- [ ] Arrastré `Fila_Completa` a **Rows**
- [ ] Arrastré `Fecha_Reporte` a **Columns**
- [ ] Arrastré `Cantidad_Negativa` a **Values**
- [ ] Veo datos en la matriz

### Configurar Filtros (Opcional)
- [ ] Arrastré `Aplicar_Filtro_Activos` a **Filters**
- [ ] Configuré el filtro = 1
- [ ] La matriz muestra solo datos filtrados

---

## 4️⃣ VERIFICACIÓN DE FUNCIONALIDAD

### Visualización
- [ ] La matriz se ve con diseño moderno
- [ ] Los encabezados tienen fondo negro/oscuro
- [ ] Las filas se alternan sutilmente en color
- [ ] Los valores negativos están en rojo
- [ ] El scrollbar se ve personalizado
- [ ] Veo los dos botones en la parte superior

### Botón Exportar a Excel
- [ ] Veo el botón "📊 Exportar a Excel"
- [ ] El botón tiene color púrpura/morado
- [ ] Hice clic en el botón
- [ ] Se descargó un archivo .xlsx
- [ ] Abrí el archivo en Excel
- [ ] Los datos están correctos
- [ ] El formato se ve profesional
- [ ] Los valores negativos están en rojo en Excel
- [ ] Los encabezados tienen formato especial

### Botón Copiar
- [ ] Veo el botón "📋 Copiar"
- [ ] El botón tiene color rosa/magenta
- [ ] Hice clic en el botón
- [ ] Vi notificación verde "✅ Datos copiados"
- [ ] Abrí Excel (o similar)
- [ ] Presioné Ctrl+V (Cmd+V en Mac)
- [ ] Los datos se pegaron en formato tabla
- [ ] Las columnas están separadas correctamente

---

## 5️⃣ INTERACTIVIDAD

### Respuesta a Filtros
- [ ] Agregué un slicer de fechas
- [ ] La matriz se actualiza al cambiar el filtro
- [ ] Agregué un slicer de otra columna
- [ ] La matriz responde correctamente

### Filtros Cruzados
- [ ] Hice clic en una barra de otro gráfico
- [ ] La matriz se filtra correctamente
- [ ] Los botones siguen funcionando

## 6️⃣ RESPONSIVE Y DISEÑO

### Diferentes Tamaños
- [ ] Hice la visual más pequeña - se adapta bien
- [ ] Hice la visual más grande - se expande bien
- [ ] Probé en modo lectura - funciona
- [ ] Los botones son visibles en diferentes tamaños

### Scroll
- [ ] Si hay muchos datos, el scroll funciona
- [ ] El scroll horizontal funciona (muchas columnas)
- [ ] El scroll vertical funciona (muchas filas)
- [ ] Los encabezados se mantienen fijos al hacer scroll

---

## 7️⃣ RENDIMIENTO

### Con Datos Reales
- [ ] La matriz carga rápidamente
- [ ] No hay lag al hacer scroll
- [ ] La exportación es rápida
- [ ] La copia es instantánea

### Power BI Service
- [ ] Publiqué el reporte en Power BI Service

- [ ] Los botones funcionan en la versión web

## 🐛 SOLUCIÓN DE PROBLEMAS

### Si algo no funciona, verifica:

#### ❌ No veo datos
- [ ] Revisé que los tres campos estén configurados
- [ ] Verifiqué que hay datos después de aplicar filtros
- [ ] Comprobé que `Aplicar_Filtro_Activos` no filtra todo

#### ❌ Los botones no aparecen
- [ ] La visual tiene suficiente altura (mínimo 300px)
- [ ] Intenté redimensionar la visual

#### ❌ Exportar no funciona
- [ ] Probé en otro navegador (Chrome recomendado)
- [ ] Verifiqué permisos de descarga del navegador
- [ ] Revisé si hay bloqueador de pop-ups activo

#### ❌ Copiar no funciona
- [ ] Probé en otro navegador moderno
- [ ] Verifiqué permisos del portapapeles
- [ ] Intenté copiar de nuevo (a veces pide permiso la primera vez)

#### ❌ Los colores no se ven bien
- [ ] Ajusté el tema de Power BI
- [ ] Revisé las opciones de formato de la visual
